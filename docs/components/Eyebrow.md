# Eyebrow

A short uppercase, tracked label that sits directly above a headline, in Storyville Red on light grounds.

**Provide:** `children` (2–4 words), optional `as` element.

- Always followed by a Bebas Neue heading (`svr-display-h1` or `svr-subheading-h2`).
- Turns `color-text-reversed` automatically inside dark and red `Surface`s (red on charcoal fails contrast).
- Never use it as a standalone heading or for sentences.

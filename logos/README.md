# Logos

Storyville RD's mark (a rectangle cut by a winding S-shaped road), wordmark ("STORYVILLE" light, "RD" bold) and tagline ("YOUR PATH. YOUR STORY"). All are transparent PNGs in two single-ink versions:

- **charcoal** (ink #211D1B, `color-text-primary`): use on `color-bg-light` and `color-surface-alt`.
- **offwhite** (ink #FAF8F5, `color-text-reversed`): use on `color-bg-dark` and `color-accent`.

| File | Use |
| --- | --- |
| `storyville-logo-stacked-*` | Primary logo: mark above wordmark and tagline. Covers, title slides, end cards. |
| `storyville-logo-horizontal-*` | Mark beside the wordmark, no tagline. Headers, letterhead, email signatures. |
| `storyville-wordmark-*` | Wordmark alone, where space is tight or the mark appears nearby. |
| `storyville-mark-*` | The S-road mark alone. Favicons, avatars, watermarks. |

- Never redraw, recolor, stretch or rebuild the logo in live type; always place one of these files.
- Never place the charcoal version on dark or red grounds, or the off-white version on light grounds.
